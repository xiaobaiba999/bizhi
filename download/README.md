## v1.4.2 更新（屏蔽记录从此永久保留）

- 升级安装全程护送用户数据目录（%APPDATA%\壁纸工坊），旧版卸载器再也删不到；
  护送失败（目录被占用）时自动跳过静默卸载，改用外科清理（只清安装目录，绝不碰数据）
- 数据库永不因缺表/缺列重建：有效 SQLite 一律保留，缺的表/列由服务端启动时自动修补，已有记录一条不丢
- 卸载向导改为主动勾选「同时删除应用数据」才清数据，正常卸载不丢屏蔽记录
- 分类精简为「电脑壁纸 / 手机壁纸」；网页版自选下载位置持久保存（IndexedDB）

> 直接覆盖安装即可，无需卸载旧版本。
